# Discovery

This directory contains investigation material for questions that are still materially
unresolved.

Discovery may be created before or during implementation when evidence, alternatives,
constraints, risks, or uncertainty must be preserved beyond one conversation.

It is not an authority for approved behavior, accepted decisions, implemented
architecture, or reusable empirical facts once those have durable owners elsewhere.

Use the authority defined in `docs/development/documentation-policy.md`:

- approved normative behavior → `docs/specifications/`;
- architectural decisions and rationale → `docs/decisions/`;
- implemented architecture → `docs/architecture/`;
- reusable empirical evidence → `docs/reference/`;
- actionable execution work → GitHub Issues.

Once a Discovery question is resolved, promote its durable conclusions and remove or
reduce the Discovery material that no longer has a unique responsibility.

Git history preserves retired Discovery documents; they do not need to remain in HEAD
solely as historical records.
